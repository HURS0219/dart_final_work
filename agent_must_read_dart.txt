9.网页端的编写：六个主界面，界面一负责识别连接到的4个，也就是每一个电机，界面二负责测试和调节两个驱动拉簧的3508电机，界面三负责测试和调节转扳机丝杆的3508电机，界面四负责测试和调节转yaw轴的2006电机（二三四这四个界面都设有独立的pid调节功能，并且要求修改之后数据不能丢失），界面五负责总控调节四个电机（也就是调节和测试好了之后直接再这个界面里面正是驱动所有的电机），界面六负责比赛的自动化运作，yaw轴通过视觉实时修正至绿光的中心，扳机电机和拉簧电机采用人为设定（比赛的时候移动靶是在一条水平的滑轨上运动，因此不需要考虑纵向的改变，y距离是不变的，初速度不用变，拉簧的德尔塔x不用变，每次电机的转动圈数不用变，至于这个圈数值，由场地上人工调节和测试得到结果），同时运行一套自动化程序
10，细说这套自动化程序：yaw轴实时对齐绿光；扳机电机不动；飞镖放上后，拉簧电机驱动拉簧，将发射台拖至底部的发射位，然后舵机转到预备档实现扣住发射台，然后拉簧电机反转相同的圈数（这个圈数是人工设定好的，因为发射托口需要复位所以需要反转回原来的版本），然后舵机转动复位，扳机扣下，发射台拖着飞镖加速，，飞镖飞出
11.抽象状态机：舵机：标准位，预备位（发射位：舵机在某个人为设定的角度；预备位：舵机在某个人为设定的角度）；拉簧电机：标准位，预备位（标准位：电机复位；预备位；电机转了某个人为设定的圈数）；yaw电机：自瞄位，制导位（自瞄位：目标靶是固定靶时，发射架转yaw自动瞄准；制导位：目标靶是随机移动靶时，发射架yaw进入初始状态，发射后由制导飞镖自行制导，发射架的初始状态即0度，人为摆放发射架位置实现）
12.状态机下实现的自动化程序：1.yaw电机状态人为选择；2.扳机电机人为设定；3.舵机：标准位；4.拉簧电机：标准位；5.拉簧电机：预备位；6.舵机：预备位；7.拉簧电机：标准位；8.舵机：标准位
13.为了实现状态机，拉簧电机的标准位设置为0圈，预备位设置为人为设定的x圈，通过在人为设定的0圈和x圈之间的变换实现状态机的切换；舵机的标准位设定为人为调节的x度，预备位设定为人为调节的y度

附录 D：视觉子系统
D.1 硬件与算法
项目	方案
视觉模块	OpenMV
识别目标	铝框上的绿光点
算法	颜色阈值 + 找色块；用方框框住铝框后取绿光中心
输出	绿光中心的水平坐标 x
传输	SPI 发送给 C 板
控制目标	yaw 电机转动，使 x 对准画面中心
复用	复用已有"OpenMV 识别绿光制导飞镖"方案，难度更低
D.2 控制逻辑
OpenMV 每帧输出绿光中心 x。

C 板通过 SPI 读取 x。

计算偏差 err = x - x_center。

yaw 电机 PID 调节，直到 |err| < 阈值。

对准后进入发射流程（对应原文档第 10、12 条）。

建议明确：SPI 读取周期、视觉帧率、yaw 控制周期，三者关系决定闭环带宽。

附录 E：异常与安全
E.1 丢失目标
行为：自动将 yaw 回 0（制导位/初始位）。

指示：异常指示灯亮起。

恢复：重新识别到绿光后，指示灯灭，yaw 重新进入自瞄闭环。

E.2 其他异常（建议补充）
异常	建议处理
拉簧电机堵转	电流限幅 + 超时报警
舵机卡死	超时检测 + 指示灯
CAN 掉线	电机失能 + 指示灯
串口/WiFi 掉线	保持最后状态或安全停机
急停	物理急停按钮，切断电机使能
E.3 指示灯定义（建议）
状态	指示
正常	常亮/慢闪
丢失目标	快闪
CAN/串口异常	双闪
急停	常灭或红色常亮
