# WiFi 多电机网页控制 / 调参 标准应用 (wifi_motor_web v2.1)

用 **ESP32 (MicroPython)** 做 WiFi 热点 + 网页，手机浏览器即可**同时控制/调参多个电机**
（一条 CAN 总线上 GM6020 / M3508 / M2006 混挂，最多 4 个）。
网页端电机无关，只认一套通用协议；具体电机由 STM32 端实现。

---

## 1. 架构

```
手机网页 --WiFi--> ESP32(网页+协议) --UART--> STM32(多电机驱动) --CAN--> 多个电机
```

- **ESP32**：跑本应用 `main.py`，提供网页、HTTP、串口协议、预设保存。
- **STM32**：跑实现「通用协议」的 app（本包 `stm32/`，对应 `UserApp/robot/wifi_gm6020`）。
- 两者 UART 连接（默认 115200 8N1）。

---

## 2. 硬件连接

| ESP32 | STM32 (F407 C板) |
|---|---|
| GPIO17 (TX) | PG9  (USART6_RX) |
| GPIO18 (RX) | PG14 (USART6_TX) |
| GND | GND (必须共地) |

电机接 STM32 的 CAN（CANH↔CANH、CANL↔CANL、两端 120Ω、电机 24V 供电）。
**同一总线上每个电机拨码 ID 必须不同**（M3508/M2006 反馈帧都是 `0x200+ID`）。

## 3. 烧录

### STM32
```
cmake -G Ninja -S . -B cmake-build-wifi_gm6020 -DROBOT_TYPE=wifi_gm6020
cmake --build cmake-build-wifi_gm6020
# 用 JLink/OpenOCD 烧 cmake-build-wifi_gm6020/control-2026.hex
```

### ESP32 (MicroPython)
```
python -m mpremote connect COM6 fs cp main.py :main.py
python -m mpremote connect COM6 reset
```
（首次需先烧 MicroPython 固件）

## 4. 使用

1. 连 WiFi：默认 `MOTOR_CTRL` / `12345678`（配置区可改）；
2. 浏览器打开 `http://192.168.4.1`；
3. **先点“停止”**（扫描/添加/设零只在停止档可用）；
4. “**扫描电机**” → 每个反馈 ID 选类型 → “**添加**”（每个电机都加一遍）；
5. 列表里点某电机的“**选**” → 调参区显示**该电机自己的**参数 → 改（尤其**减速比**）→ “**应用参数**”；
6. 切“**速度/角度**”，滑块**同时驱动所有电机**，列表显示各电机实际转速；
7. “**保存/恢复**”可存/取速度、角度目标值。

> 安全：网页失联 1.5s 自动停车（ESP32）；STM32 另有 1s 指令超时看门狗。

## 5. 通用协议

**ESP32 → STM32**（ASCII，`\n` 结尾）

| 帧 | 含义 |
|---|---|
| `C,<mode>,<value>` | 控制全部。mode 0停/1速度(RPM)/2角度(deg×10) |
| `A,<type>,<id>` | 添加电机（type 0=GM6020,1=M3508,2=M2006） |
| `X` | 清空电机列表 |
| `U,<slot>` | 选择要调参的电机（槽位） |
| `P,<id>,<value>` | 设置“所选电机”的参数（浮点×100） |
| `Z` | 全部设零（当前方向=角度0°） |
| `S` / `PING` | 扫描 / 自检 |

**STM32 → ESP32**

```
F,<mode>,<count>[,<slot>,<type>,<id>,<rpm>]*count,<sel>,<10参数...>,<limit>
S,<n>,<fb_id...>
```
- `rpm` 为**输出轴(轮子)转速**；`sel` 为所选电机槽位；参数为所选电机的参数。

**参数 id**：1 FF / 2 Kp / 3 Ki / 4 I限幅 / 5 角度Kp / 6 限幅 / 7 角度Kd / 8 角度斜率 / 10 减速比 / 11 角度死区 / 12 角度限速。

> 帧间隔建议 ≥20ms，否则空闲中断收包会粘连。

---

## 6. 关键说明

- **速度/角度以“输出轴”为单位**：内部 `电机RPM = 输出RPM × 减速比`、`电机角度 = 输出角度 × 减速比`。
  减速比可在网页改（默认 GM6020=1、M3508=19.2、M2006=36；你的 14:1 就填 14）。
- **每个电机一套独立参数**（FF/Kp/Ki/减速比/死区/限速/限幅），互不影响，掉电保存。
- **角度模式为串级**：位置环 → 速度目标(限速) → 速度环(内环)。带**死区**防抖、**限速**防失控。
- **角度模式用单圈编码器 + 多圈计数**：同一上电周期内可转到任意输出角度；但**断电后绝对位置会丢**，
  每次上电请先转到参考方向按“全部设零”。
- **掉电保存**：参数 + 电机列表 + 零点存 STM32 内部 Flash（停止时写入）。

---

## 7. 换电机

STM32 端通用驱动支持 GM6020/M3508/M2006，在网页上扫描选类型即可，无需改代码。

| 电机 | 控制帧(ID1-4/ID5-8) | 数值范围 | 反馈帧 |
|---|---|---|---|
| GM6020 | `0x1FF` / `0x2FF` | ±30000 | `0x204+id` |
| M3508 | `0x200` / `0x1FF` | ±16384 | `0x200+id` |
| M2006 | `0x200` / `0x1FF` | ±10000 | `0x200+id` |
